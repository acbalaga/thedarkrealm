# Security

The Dark Realm stores one save in the player's own browser and sends nothing anywhere. No personal data is collected, stored or transmitted.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository (Security tab, Report a vulnerability). Please do not open a public issue for something exploitable.

## What is not a vulnerability

Cheating. The game is offline and the save belongs to the player, so editing it, changing the clock or replaying a save is accepted and bounded rather than prevented. See `docs/design/SECURITY_MODEL.md` section 3 for what is defended and what is accepted.
